# Azachess

Браузерная шахматная платформа на HTML, CSS и JavaScript. Сборщик и пакетный менеджер не используются.

## Страницы

- `index.html` — главная, настройка и подбор онлайн-игры.
- `play.html` / `app.js` — партия против Stockfish.
- `multiplayer.html` / `multiplayer.js` — онлайн-комнаты и приглашения.
- `analysis.html` / `analysis-app.js` — доска анализа.
- `auth.html`, `profile.html`, `search.html`, `settings.html` — аккаунт и настройки.

Firebase Auth и Firestore подключаются через `firebase-logic.js`. Шахматная библиотека и Stockfish загружаются с CDN.

## Локальный запуск

Откройте терминал в каталоге с HTML-файлами и запустите простой HTTP-сервер, например:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Не запускайте страницы через `file://`: браузерные ES-модули требуют HTTP(S).

## Публикация

Страницы статические, поэтому совместимы с GitHub Pages. Публикация должна указывать на каталог, содержащий `index.html` и остальные страницы.

## Firebase и безопасность

Веб-конфигурация Firebase находится в `firebase-logic.js`; сама по себе она не заменяет серверные правила доступа. Действующие Firestore Rules находятся в Firebase Console. Сейчас права на `/queue` и `/pvp_games` разрешают любому вошедшему пользователю читать и изменять документы этих коллекций. Перед публичным использованием правила нужно ужесточить совместно с протоколом матчмейкинга; простая замена правил может сломать подбор соперника и ссылки-приглашения.
